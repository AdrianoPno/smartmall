# 🏢 SmartMall — Central de Clientes para Shopping

Projeto de estudo inspirado em vaga real (Ancar Ivanhoe), com foco em NestJS, arquitetura modular, Firebase Auth e boas práticas de desenvolvimento.

---

## 🎯 Objetivos

- Desenvolver uma API escalável para gestão de usuários, lojistas e administradores de um shopping
- Utilizar autenticação moderna com Firebase
- Seguir princípios de arquitetura limpa, modularização e testes automatizados com Jest
- Commitar o projeto desde o início com estrutura clara e prática
